26 HTML Tags

HTML Tag What It Does Example
<html>Starts the HTML document.<html>
<head>Contains information about the webpage.<head>
<title>Sets the title of the webpage.<title>My Page</title>
<body>Contains the visible webpage content.<body>
<h1>Creates a large heading.<h1>Hello</h1>
<h2>Creates a second-level heading.<h2>About Me</h2>
<p>Creates a paragraph.<p>Hello World</p>
<br>Creates a line break.Hello<br>World
<hr>Creates a horizontal line.<hr>
<b>Makes text bold.<b>Bold Text</b>
<i>Makes text italic.<i>Italic Text</i>
<u>Underlines text.<u>Underlined</u>
<a>Creates a link.<a href="page.html">Link</a>
<img>Displays an image.<img src="photo.jpg">
<ul>Creates an unordered list.<ul></ul>
<ol>Creates a numbered list.<ol></ol>
<li>Creates a list item.<li>Item</li>
<div>Groups sections of a webpage.<div>Content</div>
<span>Groups small pieces of text.<span>Text</span>
<table>Creates a table.<table></table>
<tr>Creates a table row.<tr></tr>
<th>Creates a table heading cell.<th>Name</th>
<td>Creates a table data cell.<td>John</td>
<header>Creates the header section.<header>Header</header>
<footer>Creates the footer section.<footer>Footer</footer>
<button>Creates a clickable button.<button>Click Me</button>
