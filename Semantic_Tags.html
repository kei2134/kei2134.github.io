Semantic Tags Explained

<header>

<header> is an HTML semantic tag, it acts like a introduction to a webpage. It could contain things like logos, navigation, and headings.

Did you know <header> is also a self-contained tag? This means that <header> is a standalone tag which means it could be used by its own.

<footer>

<footer> is an HTML element is a structural semantic tag used to define the bottom or concluding section of a webpage or a specific content section.

<main>

<main> It is a semantic tag introduced in HTML5 to enclose the central topic or unique functionality of a webpage, helping browsers, and search engines.

<section>

<section> is a HTML element represents a generic standalone section of a document or webpage. It is a semantic element, meaning it tells browser search engines and assistive technologies (like screen readers) about the meaning and structure of the content inside it.

<article>

HTML element represents a self-contained, independent composition within a webpage, application, or site. It is designed to enclose content that is independently distributable or reusable

<aside>

The <aside> HTML element represents a section of a document whose content is only indirectly or tangentially related to the main content

<figure>

The >figure> HTML element represents self-contained content—such as images, diagrams, illustrations, code snippets, or charts

<picture>

The <picture> HTML element is a powerful wrapper used to create responsive images by offering multiple source files tailored to different screen sizes, device resolutions, or file formats.

<nav>

The <nav> HTML element represents a section of a page designed specifically to provide navigation links, either to other pages or to internal sections within the same page
