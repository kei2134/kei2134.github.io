Software Development Life Cycle

SDLC Phases Main Job Artifacts
Planning Project Manager Project Plan, Overall Project Plan
Requirements Project Analyst Requirements for the following project
Design Phase UX Designer Wireframe, User Persona
Development Phase Software Developer Source code for Project
Testing Phase QA Tester Test of the source code & Test plans for bugs, glitches, etc.
Deployment DevOps Engineer Deployment of the code & sent to customers
Maintenance Maintenance Team Fixes bugs, System Recommendations reported not only from customers, but from the team
